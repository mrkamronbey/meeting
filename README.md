# Uchrashuv taklifi

Romantik uchrashuv taklifnomasi: bitta HTML fayl, server kerak emas.

- `index.html` — tayyor sahifa (GitHub Pages, Netlify yoki istalgan hostingga qo'yiladi)
- `src/taklif.html` — manba; o'zgartirgandan keyin `./build.sh` ni ishga tushiring

## Ishlatish
1. Sahifani `#yaratish` bilan oching (masalan `https://.../index.html#yaratish`) yoki pastdagi
   "O'z taklifingizni yarating" tugmasini bosing.
2. Ismlar, 3 ta sana/vaqt va xatni yozing → **Havolani yaratish**.
3. Havolani unga yuboring. Ismlar va sanalar havolaning ichida saqlanadi.

GitHub Pages: Settings → Pages → Branch tanlang → `/ (root)`.
